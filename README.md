# 南科大羽毛球场预约助手（Windows 试运行版）

使用当前登录的电脑版企业微信，按可见页面顺序点击。程序不调用预约系统接口，不读取网络请求，也不并发抢场。当前版本需要在你的电脑上验证页面控件能否被 Windows 识别；若识别失败会停止，不会盲点“预约”。

## 使用前

1. 解压后首次双击 `run.cmd`，它会创建 `config.json` 并用记事本打开。填写目标日期、时间段、球场优先顺序、使用人数和手机号，保存后再双击 `run.cmd`。若配置仍有空项，启动脚本会再次打开同一个 `config.json` 供你修改。`config.json` 只保存在本机，不要上传或分享。
2. `date` 可写 `auto_third_day`，表示**运行当天的后天**；也可写明确日期，如 `2026-09-26`。页面将今天算第 1 天，因此每晚 20:00 更新的“第 3 天”是后天。
3. `time_ranges` 从前到后是时段优先顺序，每个起止时间必须落在半小时边界。`priority_mode` 为 `time_first` 时先遍历时段，再按 `court_priority` 逐个尝试场号；改为 `court_first` 则反过来。
4. `dry_run` 初始为 `true`，程序会选时段、填人数和电话，在提交前停止。确认页面操作正常后，将它改成 `false` 才会自动点击“预约”。
5. 提前打开并登录企业微信。程序会先放大企业微信主窗口，再点击左侧「工作台」、右侧「校园场馆/会议预约系统」及底部「场地预约」，并放大弹出的预约浏览器。运行后保持电脑解锁，不要移动鼠标或切换窗口。

双击 `run.cmd` 启动。`wait_for_release` 为 `true` 时，程序到达球馆页面后等待当天 `release_time`。如果已经过了该时间，会直接继续。若只是测试白天已有的时段，可改为 `false`。

如果运行时看起来不动，先查看窗口或 `booking.log` 的最新提示。到开放时间前，程序会显示“已就绪，等待 20:00:00”，这是正常等待。要立即停止本次运行，**双击同一文件夹中的 `stop-booking.cmd`**；它根据进程编号和启动时间只结束本文件夹启动的预约脚本。运行窗口有响应时也可按 `Ctrl+C`。如果企业微信本身仍无响应，再双击 `stop-wecom.cmd` 强制关闭企业微信，然后重新打开并登录。强制关闭可能丢失尚未保存的内容。程序不允许同时启动两份预约脚本。

### `config.json` 各项怎么填

| 项目 | 作用 | 建议 |
| --- | --- | --- |
| `date` | 要预约哪一天 | 每晚抢新开放的“后天”，保留 `auto_third_day`（运行日加 2 天）；也可填写日期，如 `2026-09-25` 或 `2026-9-25` |
| `time_ranges` | 想要的起止时段，按顺序尝试 | 每段使用 `HH:mm`，起止均为半小时边界；例如 `19:00` 至 `20:00` |
| `court_priority` | 场号优先顺序 | 按喜欢程度排列 1–10 号场，可只列部分场号 |
| `priority_mode` | 备选项遍历顺序 | `time_first` 优先保住时间；`court_first` 优先保住球场 |
| `people` | 使用人数 | 填实际到场人数，如 `2` |
| `phone` | 联系手机号 | 填本人的 11 位号码，保留双引号 |
| `release_time` | 每晚开放时间 | 保留 `20:00:00` |
| `max_navigation_resets` | 页面回退异常时最多重新定位几次 | 初次使用保留 `2` |
| `max_attempts` | 最多尝试几个“时段 × 球场”组合 | 默认 `20`，可按备选项数量调整 |
| `wait_for_release` | 是否等到 20:00 再选场 | 正式预约用 `true`，白天试运行用 `false` |
| `dry_run` | 是否只填表、不提交 | 初次试运行保留 `true`；验证后才改为 `false` |

JSON 中的 `true`、`false` 和数字不要加引号。修改后保存文件，再启动程序。

预约页的“选择日期”无需操作。程序按 `date` 与运行当天比较，选择“今天”“明天”或“后天”：当天 20:00 前按页面上的两栏定位，20:00 后按三栏定位。若目标是尚未开放的后天，程序会明确报错；`auto_third_day` 应配合 `wait_for_release: true` 在 20:00 开放后使用。新打开的球场页默认显示“今天”；目标为今天时直接沿用，不再点击日期栏。目标为明天或后天时仍会检查青色选中标记，无法确认便停止。

球场页面的半小时时段使用最大化窗口坐标定位。白底青色文字表示可选，点击后实心青色表示已选；灰色时段会跳过并尝试下一个球场或时段。程序会核对实心青色格数与目标时长是否一致，无法确认时停止。修改 `time_ranges` 后请先保存 `config.json`，再重新运行。

程序按最大化截图中的位置填写人数与手机号，并通过复制当前输入框的选中文本核对填写结果；随后尝试恢复原剪贴板内容。若 Windows 暂时拒绝恢复，日志会提示，但已核对的表单流程仍会继续。无法确认焦点或内容时会停止，不会提交。两个字段都核对完成后，正式运行会直接点击页面底部的预约按钮；`dry_run: true` 时在点击前停止。

首次进入“场地预约”时，程序会先最大化独立预约窗口，等待“场地预约须知”真正显示，再把鼠标放在白色内容区快速向下滚动。它根据你提供的电脑版截图读取按钮颜色：按钮从浅绿色的“上滑阅读协议”变为深绿色的“同意本条款”后才点击，并确认弹窗消失，再进入球馆。弹窗检测同时核对中央白色面板和外侧深色遮罩，避免页面仍在加载时误判为已关闭。这个位置按你的最大化窗口截图校准；如果分辨率或显示缩放改变，无法确认时程序会停止，不会盲点。

## 界面识别

该版本通过 Windows UI Automation 查找页面中的中文文字和输入框，再模拟鼠标与键盘操作。程序会先确认企业微信已成为前台窗口；若终端或其他窗口挡住它，会明确停止。电脑版企业微信的工作台按钮可能不向 Windows 暴露名称；这时程序使用最大化窗口左侧的图标位置点击，并结合侧边栏选中背景与顶部工作台标签核对页面，避免重复点击而切回消息页。打开「校园场馆/会议预约系统」后，程序等待页面加载，再有限次点击底部「场地预约」，直到独立预约窗口出现。仍无法打开时，会等待你手动操作 30 秒，每 5 秒报告一次等待状态；检测到窗口后继续阅读须知、进入润杨羽毛球馆、选择目标号场和时段，并填写表单。也可以提前手动打开预约窗口再运行程序。

弹窗识别现在优先检查窗口标题，避免反复扫描整个浏览器界面；界面中名称明确的按钮使用精确查找。每个导航步骤都会显示进度。若你看到“仍在等待独立的场地预约弹窗”，说明程序尚未检测到新窗口，可以手动打开弹窗后让程序继续。参考的 GitHub 项目直接发送网络预约请求，因此它的速度不能用作本项目模拟点击的预期速度。

关闭须知后，程序会点击最大化场馆列表底部露出的润杨羽毛球馆卡片，并通过页面颜色变化确认是否进入球场列表。若第一次点击无效，会向下滚动并重试一次；仍未跳转就停止并说明原因。此位置依据你提供的电脑版截图校准，浏览器缩放或布局改变后可能需要重新校准。

球场列表目前按你提供的电脑版截图顺序定位：顶部依次可见 5、3、8、2、1、7 号场；9、6、4、10 号场会先快速滚动到底部再点击。点击后会检查页面是否切换，失败最多重试一次。若场馆调整球场排列或浏览器缩放，需要重新校准这些位置。后续步骤若无法识别页面控件，程序会停止并在窗口及 `booking.log` 中说明停在哪一步。日志只写尝试的场号、时段和错误，不写手机号或登录链接。

## 失败恢复

- 时段已满：返回球场列表，按配置尝试下一个备选。
- 无法进入目标球场或回退失败：有限次重新定位球场列表；超过 `max_navigation_resets` 便停止。
- 点击预约后状态不明：立即停止并提示你检查“我的预约”，防止重复提交。
- 页面显示预约成功：停止进一步尝试，并提示你核对“我的预约”中的日期、时间和场号。

## 排查

从 PowerShell 在此目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\booking.ps1 -ValidateOnly
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\booking.ps1 -Inspect
```

第二条只列出预约窗口中与操作相关的可识别控件名称。若输出为空，说明当前企业微信内嵌浏览器没有向 Windows 暴露这些控件，当前版本无法可靠操作，需要改用截图识别方案。
